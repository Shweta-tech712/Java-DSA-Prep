# Relational Operators

## Objective
Learn how to compare values in Java using relational operators.

## Operators

- ==
- !=
- >
- <
- >=
- <=

## Key Points

- Used for comparison.
- Always returns `true` or `false`.
- Commonly used in `if` statements and loops.

## Interview Questions

1. What is a relational operator?
2. What is the difference between `=` and `==`?
3. Which data type is returned by relational operators?
