# Hello World in Java

## Objective
Learn the basic structure of a Java program.

## Concepts Learned
- Java class
- main() method
- System.out.println()
- Java program execution

## Program

```java
public class HelloWorld {

    public static void main(String[] args) {
        System.out.println("Hello, World!");
    }

}
```

## Output

```
Hello, World!
```

## Key Points

- Every Java program starts from the `main()` method.
- `System.out.println()` prints output to the console.
- The public class name must match the filename.

## Interview Questions

1. What is the purpose of the `main()` method?
2. Why must the filename match the public class name?
3. What does `System.out.println()` do?
