# Assignment Operators

## Objective

Learn assignment operators used to update variable values.

## Operators

| Operator | Equivalent |
|----------|------------|
| = | Assign |
| += | a = a + value |
| -= | a = a - value |
| *= | a = a * value |
| /= | a = a / value |
| %= | a = a % value |

## Example

```java
int number = 20;

number += 10;
number -= 5;
number *= 2;
number /= 5;
number %= 3;
```

## Key Points

- Assignment operators make code shorter.
- They improve readability.
- Widely used in loops and calculations.
