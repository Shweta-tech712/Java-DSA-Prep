# Arithmetic Operators

## Objective

Learn mathematical operators in Java.

## Operators

| Operator | Meaning |
|----------|---------|
| + | Addition |
| - | Subtraction |
| * | Multiplication |
| / | Division |
| % | Modulus |

## Example

```java
int a = 20;
int b = 10;

System.out.println(a + b);
```

## Concepts Learned

- Addition
- Subtraction
- Multiplication
- Division
- Modulus
