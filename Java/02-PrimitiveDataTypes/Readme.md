# Primitive Data Types

## Objective

Learn Java's built-in primitive data types.

## Primitive Data Types

- byte
- short
- int
- long
- float
- double
- char
- boolean

## Key Points

- Java has 8 primitive data types.
- int is the default integer type.
- double is the default decimal type.
- float requires `f`.
- long values can use `L`.
- char uses single quotes.

## Example

```java
int age = 21;
double pi = 3.14;
char grade = 'A';
boolean passed = true;
```
